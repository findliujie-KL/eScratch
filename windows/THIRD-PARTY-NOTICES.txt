eScratch WPF uses the following open-source components:

AvalonEdit (MIT) — https://github.com/icsharpcode/AvalonEdit
Tesseract .NET wrapper (Apache-2.0) — https://github.com/charlesw/tesseract
Tesseract OCR (Apache-2.0) — https://github.com/tesseract-ocr/tesseract
Leptonica (BSD-2-Clause) — https://github.com/DanBloomberg/leptonica
Tesseract fast language models (Apache-2.0) — https://github.com/tesseract-ocr/tessdata_fast

English language data is downloaded by build.ps1 and bundled in the output.
Additional language data is downloaded on request from tessdata_fast.
The .NET runtime is distributed by Microsoft under its accompanying licenses
in standalone packages. Framework-dependent packages require the .NET 10
Desktop Runtime (x64). Native OCR requires the Microsoft Visual C++ 2015–2022
Redistributable (x64).
