eScratch WPF uses the following open-source components:

Html Agility Pack (MIT) — https://github.com/zzzprojects/html-agility-pack
AvalonEdit (MIT) — https://github.com/icsharpcode/AvalonEdit
Tesseract .NET wrapper (Apache-2.0) — https://github.com/charlesw/tesseract
Tesseract OCR (Apache-2.0) — https://github.com/tesseract-ocr/tesseract
Leptonica (BSD-2-Clause) — https://github.com/DanBloomberg/leptonica
Tesseract fast language models (Apache-2.0) — https://github.com/tesseract-ocr/tessdata_fast

English language data is downloaded by build.ps1 and bundled in the output.
Additional language data is downloaded on request from tessdata_fast.
System.Text.Json, System.Text.Encodings.Web, System.IO.Pipelines,
Microsoft.Bcl.AsyncInterfaces, System.Buffers, System.Memory,
System.Numerics.Vectors, System.Runtime.CompilerServices.Unsafe and
System.Threading.Tasks.Extensions (MIT) — https://github.com/dotnet/runtime
These are the .NET Framework-compatible library builds, bundled with the app;
their package version numbers do not imply a dependency on a .NET 10 runtime.
License and third-party notices are in Assets/Licenses/DotNet-Libraries-*.txt.

This build runs on Windows .NET Framework 4.8 or later. The Windows framework
is not redistributed inside the portable ZIP. The compact installer can fetch
Microsoft's signed .NET Framework 4.8 web installer only if needed.
Native OCR requires the Microsoft Visual C++ x64 Redistributable.
